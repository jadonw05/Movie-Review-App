# Movie Review Site

A full-stack web application that allows users to browse a movie database, search by directors or titles, watch trailers, and submit reviews.

---

### ⚠️ Project Status: Database Access
> **Note:** This project was developed using a database hosted on a university server. That server is no longer active. While the **complete source code** for the frontend and backend logic is available here, the application will not fetch live data without a local database connection.

---

## 🛠️ Tech Stack
* **Frontend:** React.js, Material UI
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Tools:** Yarn, Git

## 🚀 Key Features
* **Multi-Criteria Search:** Filter through the movie library by title or director name.
* **Trailer Integration:** Embedded video players to view movie trailers directly on the site.
* **Review System:** Custom interface to submit ratings and reviews for both films and trailers.
* **Performance:** Optimized backend middleware to ensure fast request handling and data delivery.
